# Анкета гостя → Google Таблица

Скрипт принимает ответы с сайта и пишет их в таблицу. Одна таблица может обслуживать все приглашения:
для каждого события автоматически создаётся отдельный лист с названием, равным `event_id`.

## Настройка (один раз, ~10 минут)

1. Создайте Google Таблицу, например «Ответы гостей».
2. В таблице: **Расширения → Apps Script**. Удалите пример кода и вставьте содержимое `Code.gs`. Сохраните.
3. **Начать развёртывание → Новое развёртывание → тип «Веб-приложение»**:
   - «Выполнять от имени»: **Я** (ваш аккаунт);
   - «У кого есть доступ»: **Все** (иначе гости без Google-аккаунта не смогут отправить ответ).
4. Разрешите доступ к таблице, когда Google попросит.
5. Скопируйте адрес вида `https://script.google.com/macros/s/…/exec` и вставьте его в `config.json` события:
   `"rsvp": { "endpoint": "https://script.google.com/macros/s/…/exec", … }`. Пересоберите сайт.
6. Проверьте: откройте сайт, отправьте тестовый ответ, убедитесь, что появилась строка на листе события. Удалите тестовую строку.

**Важно:** после правки `Code.gs` нужно **обновить развёртывание** (Управление развёртываниями → Изменить → Новая версия),
иначе продолжит работать старый код. Адрес при этом не меняется.

## Как это работает

- Сайт отправляет `POST` с телом в `text/plain` (JSON внутри). Такой запрос браузер не блокирует ограничением CORS.
- Каждый браузер гостя получает случайный `response_id`. Повторная отправка с ним **обновляет** строку — гость может изменить ответ.
- Скрипт проверяет и обрезает все поля, экранирует значения, начинающиеся с `=`, `+`, `-`, `@` (защита от формул),
  ограничивает частоту: 5 отправок в минуту с одного браузера и 300 в минуту всего.
- Время пишется в часовом поясе Asia/Almaty.

## Квоты Google

На бесплатном аккаунте у Apps Script есть суточные лимиты на время выполнения и число запросов.
Для анкет свадеб (сотни ответов в день) их хватает с большим запасом. Если вы ведёте десятки приглашений одновременно
на одном аккаунте и упираетесь в лимиты — разнесите события по разным таблицам и скриптам.
