# Публикация

Готовый сайт — это папка `dist/`: обычная статика, её можно разместить где угодно.
Ниже — Cloudflare Workers static assets (бесплатно для такого объёма).

## Разовая настройка

1. Укажите домен в `site.json`: `"base_url": "https://ваш-домен"`. Без настоящего домена превью в WhatsApp не появится:
   `og:image` должен быть абсолютным HTTPS-адресом, доступным без входа.
2. Создайте отдельный Worker для приглашений (не смешивайте с основным сайтом), например `wrangler.jsonc` в папке `invitations/`:
   ```jsonc
   { "name": "invitations", "compatibility_date": "2026-09-16", "assets": { "directory": "./dist" } }
   ```
3. Привяжите домен или поддомен в панели Cloudflare.

## Каждая публикация

```bash
node scripts/build.mjs
npx wrangler deploy
```

Нужен вход в аккаунт Cloudflare (`npx wrangler login`) или API-токен — это делает владелец аккаунта.

## Превью в WhatsApp

- Проверьте, что картинка открывается по адресу `https://ваш-домен/<slug>/og-image.jpg`.
- WhatsApp запоминает превью ссылки. Если показывается старое, поменяйте имя картинки
  (например `og-image-2.jpg` и `og.image` в конфиге), пересоберите и отправьте ссылку заново.
  Мгновенное обновление кэша WhatsApp не гарантируется.
