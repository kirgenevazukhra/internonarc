# Новое приглашение: пошагово

| Шаг | Время |
|---|---|
| 1–3. Папка, конфиг, медиа | 15–30 мин, если тексты и данные от заказчика уже есть |
| 4. Превью и сборка | 1 мин |
| 5. Проверка | 10 мин |
| 6. Публикация | 2 мин (после разовой настройки, см. DEPLOYMENT.md) |
| Анкета в Google Таблицу | разово ~10 мин, дальше — одна строка в конфиге |

Дольше всего обычно ждать материалы от заказчика: тексты, фото, музыку, точный адрес и ссылку 2GIS.

## 1. Создать папку события

```bash
cp -r events/timur-aigerim events/<slug>      # slug: латиница, цифры, дефис — например nurbek-karina
```

## 2. Заполнить `events/<slug>/config.json`

Обязательно поменять: `event_id` (уникальный), `slug` (= имя папки), `couple`, `hosts`, `date`, `time_start`,
`venue` (+ ссылка 2GIS), `program`, `rsvp.deadline`, `og.title`, `og.description`, тексты `texts.kk` / `texts.ru`.
Удалить `"demo": true`.

**Казахский текст с именами пишите целиком.** Окончания зависят от имени: «Темір **мен** Әйгерім**нің**»,
но «Нұрбек **пен** Карина**ның**». Подставить имя в готовый шаблон фразы нельзя.
Тексты, написанные не носителем, отдайте на проверку.

Монограмма задаётся на каждом языке: `"monogram": { "kk": "Т & Ә", "ru": "Т & А" }`.

Секции отключаются в `sections`, например `"dress_code": false`.

## 3. Медиа

- `audio/music.mp3` — трек, на который у заказчика есть права. mp3 128 kbps, до ~1,5 МБ.
- Картинки — WebP, по ширине не больше 960 px.

## 4. Превью и сборка

```bash
node scripts/og-image.mjs <slug>    # рисует og-image.jpg 1200×630 по конфигу (нужен Playwright)
node scripts/build.mjs <slug>       # проверяет конфиг и собирает dist/<slug>/index.html
```

Сборка остановится с понятной ошибкой, если в конфиге что-то не так. Предупреждения со знаком `!` прочитайте.

## 5. Проверить

```bash
cd dist && python3 -m http.server 8000      # открыть http://localhost:8000/<slug>/
```

- Открыть конверт, послушать музыку, пролистать до конца на обоих языках.
- Проверить дату в календаре, отсчёт, адрес, ссылку 2GIS.
- Отправить тестовый ответ в анкете, проверить строку в таблице, удалить её.
- Именная ссылка: `/<slug>/?to=Айгерим`.
- **На своём телефоне:** iPhone Safari, Android Chrome, открыть ссылку из WhatsApp и из Instagram.

## 6. Опубликовать

См. `DEPLOYMENT.md`. После публикации отправьте ссылку себе в WhatsApp и проверьте превью.
